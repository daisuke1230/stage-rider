# Stage Rider

可在瀏覽器中填寫、編輯、列印成 A4 PDF 的舞台需求表。支援舞台配置圖、演出者需求、曲目需求、備註、整張表匯入匯出，以及適合紙本提交的列印版面。

## 功能

- 直接開啟 `index.html` 即可使用，不需要後端或安裝套件
- 網頁上方會顯示工具用途與瀏覽器建議，列印時不會出現在 PDF
- 基本資料欄位包含日期、表演者、聯絡人、聯絡方式、出場順序
- 可列印／另存 PDF，預設檔名為 `[日期]_[表演者]_舞台需求`
- 預設 5 位演出者與 5 首曲目時會嘗試壓成一張 A4
- 內容放不下時會自動分成最多兩張 A4
- 第二頁列印時會帶入日期、表演者、聯絡人、聯絡方式與出場順序，避免紙本分頁後遺失資訊

## 舞台配置圖

- 可新增文字（器材）、演出者、麥克風、監聽、音箱、電力
- 文字（器材）、音箱與電力物件可直接編輯文字
- 演出者物件以圓形顯示
- 麥克風與監聽使用方向性圖示，物件可旋轉
- 舞台物件可拖曳、框選多選、旋轉、刪除
- 旋轉以 45 度為單位
- 可水平對齊、垂直對齊、左右平均、上下平均
- 支援舞台配置操作復原
- 在演出者需求輸入「演出者／樂器」時，舞台配置圖會自動建立對應的演出者圓形物件
- 舞台配置圖上方標示舞台後方，下方標示觀眾席 / FOH
- 舞台配置的編輯工具不會出現在列印／PDF 裡

## 演出者需求

- 預設 5 位演出者，可新增到最多 15 位
- 可刪除、拖曳排序
- 欄位包含演出者／樂器、訊號來源、自帶設備、監聽方式、監聽內容、備註
- 訊號來源可從自製下拉選單選擇，也可以自行輸入
- 監聽方式可從自製下拉選單選擇，也可以自行輸入
- 訊號來源預設選項包含麥克風、`Line in (mono)`、`Line in (stereo)`、播放設備、不確定
- 監聽方式預設選項包含無、舞台監聽、耳機/IEM、自備監聽、不確定
- 自帶設備欄位可直接填寫，例如效果器、筆電、手機
- 監聽內容可填寫例如人聲大、伴奏、全部
- 第一列會顯示填寫提示，點擊欄位時提示會暫時消失；沒有輸入內容時會顯示回來

## 曲目需求

- 預設 5 首曲目，可新增到最多 15 首
- 可刪除、拖曳排序
- 欄位包含曲順、曲名、長度、燈光需求、音響需求、備註
- 長度使用分:秒輸入，曲目時間會自動加總
- 燈光需求第一列會顯示提示：亮、暗、閃爍、色系、指定時間
- 長文字會自動換行，表格高度會跟著調整

## 匯入與匯出

按下「匯出整張表」可將目前整份表單輸出成 JSON 檔，預設檔名格式為：

```text
[日期]_[表演者]_preset.json
```

匯出的內容包含：

- 基本資料
- 舞台配置圖
- 演出者需求
- 曲目需求
- 備註

其他人可使用「匯入整張表」載入 JSON，繼續填寫或沿用同一份舞台需求模板。

## 清除資料

「清除整張表」會先跳出確認視窗。確認後會清除目前填寫內容、舞台配置與本機暫存，並回到預設 5 首曲目、5 位演出者的狀態。

## 日期格式

日期可手動輸入，也可使用旁邊的月曆選單。

建議格式：

```text
20260630
```

若輸入 `2026/06/30` 或 `2026-06-30`，欄位會自動整理成 `20260630`。

## 使用建議

- 建議使用 Chrome 或 Edge 填寫、列印與另存 PDF。
- Safari 可使用，但不同版本的列印、日期選單與表單控制項行為可能略有差異。
- 若內容非常長，仍可能超過 A4 的物理限制，提交前建議先預覽 PDF。
- 表單會使用瀏覽器 localStorage 暫存舞台配置；若要跨裝置或傳給其他人，請使用「匯出整張表」。
