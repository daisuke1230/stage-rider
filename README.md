# Stage Rider

簡單的 A4 列印版舞台需求表，可在瀏覽器中填寫曲目、演出者需求與舞台配置圖，並列印或另存成 PDF。

## 功能

- A4 直式列印版面
- 日期、團體名稱、演出順序欄位
- 可拖曳編輯的舞台配置圖
- 舞台物件：文字、麥克風、監聽、DI
- 舞台物件可拖曳、框選、旋轉、刪除
- 曲目需求：曲名、時間、燈光需求、音響需求、備註
- 曲目時間自動加總
- 演出者需求：演出者／樂器、輸出方法、自帶設備、監聽需求
- 輸出方法可下拉選擇，也可自行輸入
- 自帶設備勾選後才可填寫設備名稱
- 曲目與演出者可新增、刪除、拖曳排序
- 舞台配置可匯出／匯入 preset JSON
- 列印／另存 PDF 時自動使用 `[日期]_[團體名稱]_舞台需求` 作為預設檔名

## 使用方式

直接用瀏覽器開啟：

```text
index.html
```

建議使用 Chrome 或 Edge 進行列印與另存 PDF。Safari 可使用，但不同版本的列印行為可能略有差異。

## 日期格式

日期可手動輸入，也可使用旁邊的月曆按鈕選擇。

建議輸入格式：

```text
20260630
```

若輸入 `2026/06/30` 或 `2026-06-30`，欄位會自動整理成 `20260630`。

## 輸出 PDF

按下「列印／另存 PDF」後，瀏覽器會開啟列印視窗。另存 PDF 時，預設檔名會依照表單內容產生，例如：

```text
20260630_MEOW_舞台需求.pdf
```

## 舞台配置 preset

按下「匯出舞台配置」可將目前舞台配置輸出為 JSON 檔。預設檔名格式為：

```text
[日期]_[團體名稱]_preset.json
```

其他人可使用「匯入舞台配置」載入 preset，沿用同一份舞台模板繼續填寫。


## 注意事項

- 表單資料主要存在瀏覽器畫面與 localStorage 中，請在清除瀏覽器資料前先匯出需要保留的舞台 preset。
- 若欄位內容非常長，A4 單頁仍有物理限制，列印前建議先預覽。
- Safari 的 PDF 列印引擎與 Chrome / Edge 不同，若版面要求精準，建議使用 Chrome 或 Edge 輸出 PDF。
